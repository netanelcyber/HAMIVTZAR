================================================================================
TROUBLESHOOTING
================================================================================

Connection refused?
  → Verify target is reachable: ping 192.168.1.100
  → Check port open: nmap -p 443 192.168.1.100
  → Test SSH: ssh admin@192.168.1.100

Binary not found?
  → Extract from system: scp admin@192.168.1.100:/bin/httpd ./fortios_0167.bin
  → Verify it exists: file fortios_0167.bin

ROP gadgets not found?
  → Use GHIDRA to manually locate gadgets:
    - Search: Memory → Find Bytes → \x5f\xc3 (POP RDI; RET)
  → Or use: ROPgadget --file fortios_0167.bin | grep "POP RDI"

Exploitation fails?
  → Check ROP gadget addresses match 0x402a0a, 0x402a0c, 0x402a0e, 0x4d4567
  → If changed in 0167, update exploit_automation.py
  → Re-extract binary and analyze
